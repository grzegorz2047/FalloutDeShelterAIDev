# Deep Shelter 3D

Oryginalna gra zarządzania podziemnym schronem dla Nintendo 3DS, rozwijana jako aplikacja homebrew w C++ z użyciem devkitARM, libctru, Citro3D i Citro2D.

Projekt nie jest powiązany z Bethesda Softworks ani marką Fallout. Nie używa nazw, kodu, tekstów ani assetów pochodzących z komercyjnych gier.

## Status

Projekt znajduje się na etapie inicjalizacji. Plan prac jest prowadzony w GitHub Issues, począwszy od epika #1.
